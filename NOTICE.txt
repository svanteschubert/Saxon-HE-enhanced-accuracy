The standalone JAR (Saxon-HE-accuracy-<version>-standalone.jar) also contains, unchanged:

  XML Resolver 6.0.23 (org.xmlresolver:xmlresolver and its "data" JAR)
  https://github.com/xmlresolver/xmlresolver, by Norm Tovey-Walsh
  Apache License 2.0, included next to this file as licenses/xmlresolver-LICENSE.txt
  in the standalone JAR and in the release ZIP

It runs without further JARs, for instance:

  java -jar Saxon-HE-accuracy-<version>-standalone.jar -s:input.xml -xsl:stylesheet.xsl -o:output.xml
